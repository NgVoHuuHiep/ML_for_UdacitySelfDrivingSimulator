HOW TO SETUP?

STEP 1: Collect data from Udacity Self Driving Simulator. Check this GitHub for download link: https://github.com/udacity/self-driving-car-sim

STEP 2: Store the data of each track to corresponding 'track_1' and 'track_2' folder. Then zip two folders and upload to your Google Drive

STEP 3: Run the 'ipynb' code in Google Colab to extract, perform some data and image processes and start traning your model. After trained, download model to your personal computer

STEP 4: Create an env by using Anaconda, and download all libraries in 'requirements.txt'

STEP 5: Run the 'drive.py' in Anaconda command prompt and enjoy
